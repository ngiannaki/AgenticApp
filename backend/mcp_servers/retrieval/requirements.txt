# This repo has no root dependency manifest (backend/pyproject.toml is
# empty; packages are just installed into the shared .venv). Listed here so
# this file documents the retrieval server's real dependency surface beyond
# what's already pinned elsewhere (fastmcp, chromadb, llama-index-core and
# its ollama/openai llm+embedding integrations back the v1 tools and are
# already required by the indexing server / backend/infrastructure).
#
# --- v2 (LangChain) pipeline: retrieve_document_v2 / get_document_info_v2 ---
# (backend/mcp_servers/retrieval/langchain_pipeline.py)
#
# langchain / langchain-chroma / langchain-community give the hybrid
# retriever (EnsembleRetriever + ContextualCompressionRetriever), the Chroma
# vector retriever, and BM25Retriever (via rank_bm25). langchain-openai /
# langchain-ollama back get_langchain_embedding (backend/config/llm_client.py),
# mirroring v1's embedding switch (OpenAI in PROD, Ollama in DEV) so v1/v2
# vectors stay comparable even though their Chroma collections are separate.
# sentence-transformers backs the HuggingFace cross-encoder used for
# reranking (downloaded from HF on first use).
